## Order references are now gapless

Order refs are allocated from a dedicated transactional sequence (`order_sequence`
table) instead of being derived from the order auto-increment id. A rolled back
checkout (stock shortage, payment failure, any error) no longer leaves a hole in
the numbering.

The visible format does not change and the series continues seamlessly after your
highest existing ref.

**Breaking change**: `ref` can no longer be parsed to recover the order `id`.
Audit any custom module relying on `ref = 'ORD' + zero-padded id`. To customize
the ref format, alias your own implementation of
`Thelia\Domain\Order\Service\OrderRefGeneratorInterface`.

## Automatic legal invoice numbering (opt-in)

The core can now assign `order.invoice_ref` from a gapless yearly series
(e.g. `2026-000123`) when an order becomes paid, as required for French invoices
(CGI, ann. II, art. 242 nonies A).

It is **disabled by default on updated shops** so that invoicing modules already
managing this column keep full control (the core never overwrites a non-empty
`invoice_ref`). To enable it:

1. If you are switching from a module mid-year, align the counter first:
   `php Thelia sequence:set invoice_ref_<year> <last emitted number>`
2. Set the `invoice_ref_auto` configuration to `1`.

The number format can be adjusted with the `invoice_ref_format` configuration
(placeholders: `%year%`, `%number%`).

A unique index is added on `invoice_ref` — if your database already contains
duplicate invoice refs, the index is skipped with a warning and should be dealt
with manually.

## Atomic stock decrement

Order creation now decrements product stock with a single conditional UPDATE.
When stock is managed at order creation, two simultaneous checkouts can no
longer both pass the availability check and oversell: the second one is refused
with the usual "Not enough stock" error.

Stock updates driven by order status changes (e.g. payment modules that
decrement stock when the order becomes paid) keep their historical,
non-atomic behaviour for now.
